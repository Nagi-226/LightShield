# 📋 LightShield 项目契约（Project Contract）

> **建立时间**：2026-06-09 | **版本**：v1.0 | **基于**：Nagi Dev Guardrails M1 + M2
> **作用**：锁定已确认的基线，任何偏离必须经过显式重新谈判。这是集群所有 Agent 的"宪法"。

---

## 一、范围（Scope）

### ✅ 确认范围内（MVP v0.0.10）

| 优先级 | 模块 | 一句话描述 |
|:--:|------|------|
| P0 | 资产扫描 | 端口 + 服务 + 敏感目录探测 |
| P0 | 漏洞检测 | SQL注入/XSS/弱口令/老旧组件检测 |
| P0 | 中文报告 | Markdown 格式，风险分级，修复建议 |
| P1 | 自动加固 | 高危端口关闭 + 服务禁用 + Web 防护配置 |
| P1 | 规则引擎 | JSON 规则库 + 可导入新规则 |

### ❌ 明确排除

| 排除项 | 原因 |
|------|------|
| 对外主动攻击/渗透测试 | 合规 R1 |
| 批量扫描公网 IP 段 | 合规 R2 |
| 远控/后门/木马/免杀 | 合规 R3 |
| exploit/payload/post 模块 | 合规 R5 |
| SaaS 多租户平台 | v2.0+ 重盾 |
| 商业支持/付费许可 | 开源定位 |
| hackingtool 代码直接复用 | 方案A已否决 |
| 移动端 App | 不在路线图中 |

## 二、架构（Architecture）

### 已确认的架构决策（ADR）

| ADR | 决策 | 不可回退 |
|:--:|------|:--:|
| ADR-001 | 5层架构：交互层→调度层→适配层→规则层→报告层 | ✅ |
| ADR-002 | 适配器模式：BaseAdapter 抽象基类，所有扫描能力通过 Adapter 接入 | ✅ |
| ADR-003 | 技术栈：Nmap + 自研 Python 脚本 + MSF auxiliary/scanner 子集 | ✅ |
| ADR-004 | hackingtool 仅作设计参考，不进入部署包 | ✅ |
| ADR-005 | 主语言 Python 3.10+，部署包 ≤500MB | ✅ |
| ADR-006 | 8 Agent 集群开发：Claude Code 编排，其余 Agent 并行执行独立任务 | ✅ |
| ADR-007 | 双审机制：CodeWhale + Claude Code 双重审查所有代码 | ✅ |

### 架构约束

- 任何新扫描能力必须通过 BaseAdapter 子类实现
- MSF 调用必须经过白名单校验（`ALLOWED_MSF_PREFIXES`）
- 所有对外操作必须经过 `validator.validate()` 前置校验

## 三、合规红线（不可协商）

| 编号 | 红线 | 违反后果 |
|:--:|------|------|
| R1 | 禁止对外主动攻击 | 立即回滚，追溯 Agent |
| R2 | 禁止批量扫描公网 IP 段 | 代码拦截 + 输入校验层 |
| R3 | 禁止远控/后门/木马 | 关键字扫描 + 人工审查 |
| R4 | 仅允许自查自有资产 | 所有权确认弹窗 |
| R5 | MSF 仅限 auxiliary/scanner/* | 白名单机制 |
| R6 | 扫描并发 ≤20，间隔 ≥5s | 参数硬限制 |

## 四、里程碑（Milestones）

| Gate | 触发条件 | 检查内容 |
|:--:|------|------|
| **Gate 1** | 架构确认后、编码前 | 技术选型、ADR 文档、合规设计 |
| **Gate 2** | Phase 1 骨架完成 | 接口一致性、契约符合度、合规自检 |
| **Gate 3** | Phase 5 规则引擎完成（核心功能完） | 端到端可用、漏洞检测准确率 |
| **Gate 4** | v0.0.10 MVP 完成 | 全量合规审计、部署包大小、中文报告 |
| **Gate 5** | 每次扩展（用户提出新功能） | 范围漂移检测、架构一致性 |

## 五、范围漂移阀值

| 指标 | 阀值 | 动作 |
|------|------|------|
| 累积新增功能 vs 原始范围 | >30% | 🟡 提醒用户 |
| 新增功能数 | >5 | 🟡 提醒用户 |
| 无显式范围审查的连续新增 | >3 | 🔴 暂停 + 全量范围审查 |
| 架构模式改变 | 任何 | 🟠 暂停 + ADR 更新 |
| Agent 过度工程（SF-L2+） | 触发 SF-L2 | 回滚非必要变更 |
