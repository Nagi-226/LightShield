   - 仅使用 auxiliary/scanner/ 子集，通过白名单机制控制。
   - 禁止 exploit/payload/post/evasion 等所有攻击模块。

3. 技术栈最终确认（详见 PROJECT_OVERVIEW.md 第三章）：

结合上方前置项目说明，帮我完整设计并开发开源工具 LightShield 轻盾，目标用户是初创企业和个人站长，主打一键安全自检、漏洞检测、服务器加固、自有资产模拟攻防演练。

一、整体技术架构要求
1. 分层设计：交互层（简易界面）→ 核心调度层（封装 HackingTool + Metasploit）→ 规则引擎层（漏洞/攻击特征库）→ 日志报告层；
2. 严格功能隔离：彻底屏蔽 HackingTool、Metasploit 中对外攻击、横向渗透、远程控权等恶意模块，仅保留合法自检能力；
3. 增加权限校验：强制用户手动填写自有 IP/域名，代码层面拦截随机IP段扫描、公网批量探测行为；
4. 环境兼容：支持 Linux(CentOS/Ubuntu)、Windows Server，实现一键环境依赖安装。

二、必须实现的 MVP 核心功能（优先开发）
1. 资产一键自检：调用 Nmap 等能力扫描本机/自有服务器端口、开放服务、敏感目录，生成资产清单；
2. 漏洞一键检测：集成 Web 漏洞、系统组件漏洞、弱口令检测，基于 OWASP Top10 + CVE 规则库；
3. 风险分级：自动划分 高危/中危/低危 三个风险等级；
4. 全自动加固：根据检测结果，自动生成并执行 Shell/Python 加固脚本（关闭高危端口、禁用无用服务、Web 基础防护、权限加固）；
5. 自有资产模拟攻防：仅针对用户填写的自有目标，模拟常见黑客攻击行为，验证防御效果，不产生对外流量；
6. 中文可视化报告：输出易懂的风险说明、问题位置、修复建议、加固记录。

三、开发规范与输出要求
1. 采用 Python 作为主力开发语言，拆分模块化代码，方便后续迭代；
2. 所有代码增加中文注释，捕获网络异常、权限不足、工具调用失败等报错；
3. 输出完整项目目录结构、所有源码文件、部署教程、使用手册；
4. 代码中添加安全拦截逻辑：禁止输入公网陌生IP段、限制扫描范围仅为用户指定单IP/域名；
5. 不要开发任何木马、远控、对外入侵相关功能，全程坚守合规防御定位。

四、额外优化需求
基于公开攻防模拟数据，设计轻量化规则引擎，支持后续导入新漏洞规则；所有操作日志本地留存，方便用户溯源。

   1. 全程不生成木马、远控、免杀、对外入侵POC等违规代码；
   2. 代码双层防护：前端输入拦截 + 后端代码校验，双重禁止批量扫描公网IP段；
   3. 所有测试仅在本地虚拟机、自有测试服务器完成，禁止对公网陌生资产测试。

4. 交互技巧
   1. 单次只发送一条提示词，不要一次性投喂全部需求；
   2. 代码输出后先本地调试，再进行下一个模块开发；
   3. 每次对话开头追加【通用前置基准文案】，保证上下文统一。
